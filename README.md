# 3D Rocket Boost Game

## Overview

A 3D rocket landing game developed using **Unity 6 and C#**. The player controls a rocket, avoids obstacles, and safely lands on the landing pad.

## Features

* 3 challenging levels
* Physics-based rocket movement
* Space Bar and Arrow Key controls
* Moving, rotating and dropping obstacles
* Collision detection
* Sound and particle effects
* Automatic next-level loading
* Crash and level restart system

## Controls

* **Space Bar** – Thrust
* **Left Arrow** – Rotate Left
* **Right Arrow** – Rotate Right
* **Escape** – Quit Game

## Technologies

* Unity 6
* C#
* Unity Physics
* Rigidbody
* Particle System
* Audio System

## Objective

To develop an interactive 3D game and gain practical experience in **Unity, C# programming, physics, collision detection, scene management, and game design**.
