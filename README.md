# 🚀 Rocket Boost

**🎮 [PLAY ROCKET BOOST LIVE](YOUR_LIVE_GAME_URL)**

Rocket Boost is a 3D rocket landing game developed using Unity 6. Control a rocket, avoid obstacles, and safely reach the landing pad to complete each level.

👉 **Live Demo:** [Click here to play Rocket Boost](YOUR_LIVE_GAME_URL)

## 📸 Game Preview

The game features a space environment, rocket flight controls, challenging obstacles, and landing missions.

## 🛠️ Technologies Used

* Unity 6
* C#
* WebGL
* 3D Game Development

## ✨ Features

* 🚀 Rocket thrust and flight using the Space Bar.
* 🎮 Rocket rotation using the arrow keys.
* 🌌 Space-themed 3D environment.
* 🧱 Different obstacles, including moving, spinning, oscillating, and dropping objects.
* 🎯 Landing pad objective.
* 🔊 Success sound and particle effects upon successful landing.
* 🏆 Three playable levels with increasing difficulty.
* ➡️ Automatic progression to the next level after completing a level.

## 🕹️ Controls

| Key           | Action                                            |
| ------------- | ------------------------------------------------- |
| Space Bar     | Rocket thrust                                     |
| Left Arrow    | Rotate rocket left                                |
| Right Arrow   | Rotate rocket right                               |
| Up/Down Arrow | Control rocket rotation as configured in the game |

## 🎯 Objective

Launch the rocket, navigate through obstacles, control its movement, and safely land on the target landing pad. Complete all three levels to finish the game.

## 👨‍💻 Development

This project was developed as a hands-on Unity 3D game development project to practise C# scripting, Rigidbody physics, collision detection, scene management, obstacle design, and WebGL deployment.

## 🚀 How to Play

1. Open the live game link.
2. Start controlling the rocket using the keyboard.
3. Avoid obstacles while moving toward the landing pad.
4. Land successfully to unlock the next level.
5. Complete all three levels.
